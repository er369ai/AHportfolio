The problem

The product depends on systems it does not control

Anything consumer-facing that pulls data from outside inherits every one of those services’ bad days: timeouts, changed fields, silent partial responses.

So the integration boundary became the design problem. Each external service was given its own adapter, its own failure mode and its own cached last-known-good state, and the interface was designed to be honest about what is stale.

What we built

Four decisions that shaped it

01

Adapters, not direct calls

No page talks to a third party. Each service sits behind an adapter with a timeout, a retry policy and a documented response shape.

02

Last-known-good state

When an upstream fails, the platform serves the last verified data and says so, instead of showing an error or, worse, a blank.

03

Honest interface states

Loading, stale and unavailable are designed states with real copy — not spinners standing in for a decision nobody made.

04

Consumer-grade front end

Fast first render, accessible controls, and layouts that hold up on the phones the audience actually uses.

Architecture

A core that survives its dependencies

DataOwn canonical records; external data stored as cached, timestamped copies.
APISingle contract; no external call made in the request path of a page render.
IntegrationsOne adapter per service with timeout, retry and schema validation at the boundary.
Background workScheduled refreshes with backoff; failures alert instead of silently ageing.
InterfaceDesigned states for loading, stale and unavailable; mobile-first, accessible.
ObservabilityPer-integration health visible to the client, not buried in our logs.
Outcomes

Upstream failures stopped being incidents

Availability and traffic figures are the client’s to share; available on request.

An external outage now degrades one feature and shows a clear state instead of breaking pages.
Integration changes are contained to a single adapter file.
The client can see the health of each external dependency without asking us.
Consumer-facing performance held through launch traffic.
